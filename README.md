# Google Maps Lead Scraper

Turn Google Maps into a B2B lead database using [Apify](https://console.apify.com/sign-up?fpr=dx06p) actors — no code, no proxies, no maintenance.

## The pipeline

1. **Google Maps Scraper** — input `niche + city`, get names, phones, websites, reviews
2. **Contact Details** — enriches each business website for emails and socials
3. **Export CSV** — clean lead list ready for outreach

## Signals worth filtering

- < 50 reviews = small business, needs help
- No website = immediate pitch
- High reviews, no socials = reputation without marketing
